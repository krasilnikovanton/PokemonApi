### Краткое резюме проекта

* **О чем проект**: REST API сервис для управления каталогом покемонов, владельцев, категорий и системы пользовательских отзывов/рейтингов.
* **Архитектурные решения**:
  * **Repository Pattern + DI**: изоляция уровня доступа к данным через интерфейсы для удобной поддержки и тестируемости.
  * **DTO + AutoMapper**: разделение внутренних сущностей БД и внешнего API-контракта.
  * **Code-First & Migrations**: декларативное управление схемой базы данных через EF Core.
  * **Модульное тестирование**: вынесен отдельный тестовый проект (`PokemonReviewApp.Tests`) для проверки контроллеров и репозиториев с мокированием зависимостей.
* **Стек**: C#, ASP.NET Core, EF Core, AutoMapper, Swagger/OpenAPI, Unit Testing (xUnit/Moq/FluentAssertions).
